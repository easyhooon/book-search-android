# QA 절차와 검증 범위

이 문서의 140개 테스트·APK·기기·제출 패키지 결과는 제출 시점 기준입니다. Writer 제거 브랜치의 새 검증과 보장 범위는 [Writer 제거 검증](WRITER_REMOVAL.md)을 참고합니다. 제출 APK와 ZIP은 갱신하지 않았습니다.

[요구사항](REQUIREMENTS.md)의 R-ID별 재현 절차와 현재 기대 결과입니다. **APK 빌드·자동 테스트와 Android Studio 새 폴더 가져오기는 통과했으며, 현재 APK의 Galaxy 확인 범위는 아래에 구분**합니다. 표의 "기존 QA 결과"와 화면 자료는 아래 빌드에서 관찰한 결과입니다. 관련 구현·동작이 현재 코드에서도 유지된 범위는 회귀 검증 근거로 사용하며, 최신 APK에서 같은 절차를 다시 실행한 결과와 구분합니다.

## 제출 패키지 확인

- `.git`·`local.properties`·APK·시연 영상 2개·다이어그램 원본과 이미지 포함, `build/`·`.gradle/` 등 제외 확인.
- API 키 포함 여부만 확인하고 값은 기록하지 않음. 개인 `sdk.dir`는 제외.
- CRC 및 압축 해제 파일 해시 대조 통과. ZIP APK와 Galaxy에 설치한 APK의 해시 일치.
- 제출 커밋의 소스·문서와 `.git` 포함.

복원한 기존 DB의 즐겨찾기 2건은 앱 재실행 후 표시 확인. 새 저장→앱 종료→재실행, 네트워크 오류·페이지네이션, 시스템 프로세스 복원, 태블릿·폴더블의 현재 APK 검증은 미실행입니다. 아래 표의 "최신 부분 확인"은 현재 APK에서 실행한 범위만 뜻하며, "기존 QA 결과" 열에는 이전 기기 검증 범위를 그대로 남겼습니다. 참고 화면은 기존 QA 자료입니다.

## 실기기 시나리오

"검증 판정"은 기기 관찰과 자동 테스트를 함께 구분해 표시합니다. **통과 5행·최신 부분 확인 7행·기존 기기 통과 및 관련 동작 유지 26행·자동 테스트 통과 및 최신 기기 재검증 대기 6행·자동 경합 테스트 통과 및 기기 경합 미재현 1행**, 총 45행입니다.

- **통과 / 최신 부분 확인:** 최신 APK에서 실행한 결과. 부분 확인 행의 나머지 절차는 "기존 QA 결과" 열의 이전 기기 근거와 구분합니다.
- **기존 기기 통과 · 관련 동작 유지:** 2026-10-08 기기 결과와 현재 관련 소스·자동 테스트를 대조한 회귀 근거. 최신 APK에서는 해당 절차를 재실행하지 않았습니다.
- **자동 테스트 통과 · 최신 기기 재검증 대기:** 관련 자동 테스트는 통과했고 이전 기기 관찰도 남아 있지만, 변경된 재시도·쓰기 경로나 재연결 조건의 최신 기기 확인이 필요합니다. 자동 테스트가 기기 절차 전체를 대신한다는 뜻은 아닙니다.
- **자동 경합 테스트 통과 · 기기 경합 미재현:** 지연 응답을 통제한 자동 테스트는 통과. 기존 기기에서는 늦은 응답 경합이 발생하지 않았고 최신 APK에서 다시 시도하지 않았습니다.

## Compose 컴파일러 정적 진단

Kotlin 2.4.0 Compose compiler 보고서 기준의 정적 진단입니다. 앱 코드·의존성·안정성 annotation 변경 없이 외부 출력 경로만 지정한 결과입니다.

- SearchScreen·FavoritesScreen·BookDetailScreen·BookCard·PriceLine·BookDetailBody는 `restartable skippable` 판정입니다.
- Book·PriceFilter 인자는 `unstable`이지만 관련 UI는 skippable입니다. 세 UiState의 stable 판정은 기존 `@Immutable` 계약을 반영합니다.
- Strong skipping이 켜진 환경의 정적 판정이며, 실제 재구성·skip 횟수나 프레임 성능을 입증하지 않습니다.

## 검증 한계

- **동시 입력·저장 경합:** 기존 adb 확인은 입력 간격과 실제 DB 지연을 통제하지 못함. 동시 탭·연타·대기 중 화면 종료·쓰기 실패는 자동 테스트에서 별도 확인.
- **폴더블:** Fold2 안쪽 화면도 compact 너비이므로 2-pane 확인은 태블릿에서 수행. 힌지 자세별 테이블톱 배치는 구현 범위 밖.
- **프로세스 복원:** 기존 기기에서 `am kill` 후 저장 상태 복원을 확인했고, 최신 자동 테스트는 `StateRestorationTester`로 저장 상태 복원을 모사함. 최신 APK의 기기 재실행·실제 메모리 압박·프로세스 종료 중 미완료 쓰기는 미검증.
- **네트워크:** 조건부 재연결 재조회와 오류 버튼 재시도 제공([아키텍처](ARCHITECTURE.md#검색-캐시의-수명과-재조회)). TC-42는 기존 QA 관찰이며 현재 APK의 재연결 경로는 미검증. 표지는 캐시가 없으면 대체 이미지 표시.
- **정가 정책:** 0 이하·null은 자동 테스트, API 정가 0은 Galaxy에서 확인. TC-33의 기존 누락 필드 표시 근거는 유지하며, 정가 0원 표시 결과는 새 정책의 증거에서 제외.
